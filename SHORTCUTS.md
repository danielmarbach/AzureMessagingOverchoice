# Shortcuts

Start Mark and scribble!

Reminder because I tend to forget under pressure.

- Command + F1 (Brightness down) (Extended to Duplicate and back)
- Command + F2 (Brightness up) (Display menu)
- Command + . (dot) to close instead of Ctrl+C
- Mark and Scribble
  - Control + A (Arrow)
  - Control + X (Erase)
